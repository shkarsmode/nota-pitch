# Нота

Тренажёр интонации для телефона (PWA). Показывает, какую ноту ты поёшь и насколько точно, даёт петь поверх своей мелодии и каждый день проводит короткую тренировку, которая подстраивается под слабые места.

## Вкладки

**Голос.** Крупная нота, отклонение в центах и подсказка «занижаешь / завышаешь». Голос рисуется линией по 13 дорожкам До–До: октава не важна, попадание засчитывается в любой. Тап по ноте слева — она звучит и становится целью. Есть фоновая нота для подстройки на слух.

**Запись.** Сыграй или спой мелодию — приложение разберёт её на ноты и будет крутить по кругу бегущими полосками. Пой поверх: после каждого круга видно, какие ноты попал и сколько процентов времени был в ноте. Можно включить звук мелодии, замедлить темп, записи сохраняются.

**Тренировка.** Около 9 минут в день, пять видов упражнений с тремя уровнями:

- *Попадание* — услышал ноту, спел её.
- *Точный вход* — короткие ноты без подъезда снизу; измеряется промах в первые миллисекунды.
- *Ровная нота* — держать высоту, не давая ей просесть.
- *Интервалы* — спеть ноту от опорной без подсказки звуком.
- *Фразы* — спеть короткую мелодию вместе с полосками.

Приложение запоминает ошибку по каждой ноте, интервалу и навыку, чаще даёт то, что получается хуже, и поднимает уровень, когда попаданий больше 80%. На главном экране — серия дней, график точности за две недели и сравнение «было / стало».

Всё считается в браузере, звук никуда не отправляется. Прогресс хранится на устройстве.

## Как устроено

| Файл | Что делает |
| --- | --- |
| `pitch.js` | высота тона: метод McLeod (NSDF через FFT) |
| `tracker.js` | отсев мусора на переходах и коротких октавных скачков |
| `notes.js` | разбор записи на ноты, оценка ноты (вход, удержание, дрейф) |
| `trainer.js` | план тренировки, уровни, оценки, статистика |
| `roll.js` | отрисовка дорожек, полосок и линии голоса |
| `audio.js` | микрофон, тоны-подсказки, фоновая нота |
| `app.js`, `loop.js`, `train.js` | экраны и логика вкладок |

Сборки нет — это статический сайт.

```sh
python3 -m http.server 8080   # http://localhost:8080
node --test test/*.test.mjs
```

Микрофон работает только на `localhost` или по `https`. Деплой: Vercel, Framework Preset «Other», без команды сборки.
