# Нота

Тренажёр интонации для телефона. Показывает, какую ноту ты поёшь, на сколько центов промахиваешься и куда двигаться, а голос рисует линией по дорожкам нот.

- **Цель:** тап по клавише слева — нота звучит и становится целью, подсказки считаются от неё.
- **Бурдон:** тянущаяся нота-опора с квинтой или без (лучше в наушниках).
- **Удержание:** сколько секунд держишь ноту и какой процент времени попадаешь.
- Работает офлайн, ставится на экран «Домой» как приложение.

Высота определяется методом McLeod (NSDF через FFT) прямо в браузере, звук никуда не отправляется.

## Запуск

Сборка не нужна — это статический сайт.

```sh
python3 -m http.server 8080
# открыть http://localhost:8080
```

Микрофон работает только на `localhost` или по `https`.
